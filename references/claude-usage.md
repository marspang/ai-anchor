# Claude 使用说明（给最终用户）

> 这一份可以直接发给使用这台网络的人。核心只有一句：**Claude 只认出口 IP，不认你在哪。**

## 一、唯一原则

所有 Claude 会话（网页版、桌面客户端、手机 App、API）必须始终从**同一个住宅 IP** 出去。
换网络本身不会出问题，出问题的是「换了网络，但代理没生效，出口变成了当地 IP」。
同一个账号今天在这个 IP、明天在另一个 IP，是风控最敏感的信号。

## 二、台式机（推荐）

- 优先用有线连接。
- 有无线网卡的，把 Wi-Fi 关掉，避免开机自动连上手机热点。
- 热点 + 代理没启动 = Claude 立刻看到中国 IP，同账号两地登录，高风险。

## 三、笔记本

- 在家：正常使用。
- 外出：
  - 优先「手机热点 + 笔记本上的同一套代理」，确认出口仍是住宅 IP 后再开 Claude；
  - 没有代理、或不确定代理是否生效时，**不要打开 Claude**，也不要用手机 App 登录同一账号；
  - 每次换网络后，先跑一次出口校验（见第六节），通过了再开。
- 咖啡厅、酒店、公司网络通常没有你的住宅出口，不要在里面直接开 Claude。

## 四、手机

- 不要用移动网络直接登录同一个 Claude 账号，这是最常见的「一地两 IP」。
- 要么手机也接到同一个住宅出口（家里 Wi-Fi），要么不登。

## 五、开机顺序

1. 先确认路由器 / 代理已启动，TUN 正常。
2. 再打开浏览器或桌面客户端。
3. 顺序反了会有一小段直连窗口，这期间加载的页面用的就是真实 IP。

## 六、使用前 10 秒自检

```
curl -s --max-time 8 https://claude.ai/cdn-cgi/trace | grep ip=
```

输出的 IP 必须等于锚定的住宅 IP。不等就说明代理没生效，先别用。

## 七、时区与语言

- 系统时区保持与住宅 IP 归属地一致，关闭「自动设置时区」，否则出差会被改回本地，和 IP 对不上。
- 语言/区域同理，不要频繁改。

## 八、账号行为

- 不频繁切节点、不多设备同时在线、不频繁清 Cookie 或换 UA。
- 出现验证或风控提示时，先查出口 IP 有没有变，不要反复重试登录。

## 九、出问题后的自查顺序

1. `curl -s https://claude.ai/cdn-cgi/trace | grep ip=` 看出口是否还是锚定 IP。
2. 浏览器打开 `https://ip.net.coffee/claude/`，看 Trust Score、IP 属性、DNS / WebRTC 是否泄漏。
3. 再看时区、语言是否被系统改回去了。
